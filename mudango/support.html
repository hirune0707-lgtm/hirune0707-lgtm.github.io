よくある質問

  • ランキングが見られない： iOS の「設定」＞「Game Center」でサインインしてください。サインインしていなくても、ランキング以外はすべて遊べます。
  • 「30秒もどす」が使えない： 広告を最後まで見たときだけ戻せます。通信できないときや広告が無いときは使えません。
  • 広告のプライバシー設定： 同意の確認が必要な地域では、アプリの「設定」に「広告のプライバシー設定」が表示されます。トラッキングの許可は iOS の「設定」＞「プライバシーとセキュリティ」＞「トラッキング」で変更できます。
  • 記録について： 記録は端末内に保存されます。機種変更のときは、端末のバックアップから復元してください。

お問い合わせ・不具合報告

窓口は GitHub Issues です。GitHub アカウントでのログインが必要で、投稿内容はインターネット上に公開されます。個別の非公開相談窓口ではありません。この窓口は開発者のほかのアプリと共通のため、件名の先頭に「【泥だんGO!!】」と書いてください。

お知らせいただきたい情報：端末の機種・iOS のバージョン、アプリのバージョン、問題が起きるまでの操作と期待した動作。実名・メールアドレス・Apple Account などの個人情報は投稿しないでください。

Support (English)

Leaderboard: sign in to Game Center in iOS Settings. "Rewind 30 seconds" works only after watching a whole ad. Ad privacy settings appear in the App's settings in regions where consent is required; tracking permission can be changed in iOS Settings > Privacy & Security > Tracking.

Contact: GitHub Issues (public; a GitHub account is required). This is shared with the developer's other apps, so please start the title with "【泥だんGO!!】". Do not post personal information.
